## Contrato de inventário canônico (AUD15, 15/10/2026)

Este snapshot é **arquivo histórico, não componente ativo nem input para build/deploy atual**. O inventário de supply chain continua enumerando todos os manifestos rastreados, inclusive este, e mantém apenas `apps/web` como componente Node canônico. A única classificação histórica permitida é o par exato de manifestos do [snapshot](<../.runtime/production-local-20261004/source/apps/web/package.json>) e seu lockfile, com SHA-256 imutáveis conferidos contra o [manifesto de preservação](<local-runtime-archive-20261011.json>). Qualquer arquivo alterado, provenance ausente/incoerente, symlink externo, manifesto adicional em outro caminho (inclusive dentro de `.runtime`) ou componente canônico ausente faz o gate falhar. O conteúdo do snapshot não foi removido, atualizado nem declarado livre de vulnerabilidades. Uma futura execução ou reconstrução dessa instalação exige inventário/scans próprios; o PASS do produto atual não se transfere ao arquivo histórico. A [implementação do inventário](<../scripts/phase11/frontend_supply_runtime_gate.py>) mantém os arquivos arquivados na enumeração geral, inclusive para scan de segredos; não há exclusão ampla do diretório.

O wrapper `local_composition.py` contém uma composição explícita para testes locais, incluindo substituições de prontidão e de entrega de e-mail. As variantes dos guards diferem do main atual. Este arquivo histórico não promove essas substituições à produção. Sintaxe Python, JSON e shell foi validada; a pilha não foi reiniciada nem certificada novamente.
